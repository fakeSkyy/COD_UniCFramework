# FreeRTOS implementation host tests

These suites compile the production sources from `04_impl/rtos/freertos` directly against a
minimal host contract. The committed mocks under `mocks/` are generated by the pinned official
CMock 2.7.0 in `tests/cmock`; no host build needs Ruby.

Covered modules and paths:

- task: static creation validation, priority/stack conversion, notifications in task and ISR
  contexts, wait/delay timeout boundaries, scheduler-state guards, and lifecycle forwarding;
- mutex: normal and recursive creation/locking, timeout conversion, invalid storage, and illegal
  blocking contexts;
- semaphore: counting/binary creation, task and ISR give/count paths, ISR yield, full/error paths;
- memory: allocator binding, allocation failure, free and `free(NULL)`;
- hooks: idle storage, fatal diagnostics/interrupt masking, and pre/post-scheduler SysTick routing;
- fault: exception enabling, barriers, MSP/PSP dispatch, frame fields, SCB status decoding, and
  unknown/null-frame handling. ARM naked handler assembly remains target-only.

Run all host tests:

```sh
./tests/run_tests.sh /tmp/COD_UniCFramework-build-tests
```

Run only these suites:

```sh
ctest --test-dir /tmp/COD_UniCFramework-build-tests -L rtos --output-on-failure
```

Regenerate mocks only after changing the host FreeRTOS contracts:

```sh
RUBY=/path/to/ruby ./tests/scripts/cmock/generate.sh \
  --domain impl-freertos --output /tmp/cod-cmock-freertos
./tests/scripts/cmock/check.sh
```
