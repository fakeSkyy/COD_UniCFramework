# 02_device host tests

These Unity suites compile each `02_device` production `.c` directly into its own host executable.
Hardware-facing calls are isolated by mocks generated by the repository-vendored official
ThrowTheSwitch CMock 2.7.0. Hardware-independent CRC, PID/LPF, RLS, Seq and fast-math behavior is
linked from the real `06_utils` sources.

Regenerate committed mocks deterministically with:

```sh
./tests/scripts/cmock/generate.sh --domain unit-device --output /tmp/cod-cmock-unit-device
./tests/scripts/cmock/check.sh
```

The unified generator resolves Ruby in this order: `RUBY`, `CMOCK_RUBY_ROOT`, `ruby3.2`, then
`ruby`. `cmock.yml` enables strict ordering and callback,
ignore, ignore-argument, any-argument and return-through-pointer plugins. Every CMock suite calls
Init before a case, then Verify before Destroy in teardown. `mock_bmi088_peer` is linked only into
`test_dev_bmi088_store`, preventing collisions with the real BMI088 implementation.

Run all host tests or only this layer with:

```sh
./tests/run_tests.sh /tmp/COD_UniCFramework-build-device
ctest --test-dir /tmp/COD_UniCFramework-build-device -L device --output-on-failure
```
