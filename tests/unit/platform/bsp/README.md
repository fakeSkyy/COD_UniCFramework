# Platform BSP host tests

This directory tests every production source in `03_platform/bsp` directly on the host. There is one Unity executable per `plat_*.c` (`adc`, `can`, `dwt`, `flash`, `gpio`, `iic`, `pwm`, `spi`, and `uart`) plus a suite for the header-only `plat_dma_buf.h` contract. UART links the production `06_utils/util_ringbuf/util_ringbuf.c`.

The committed mocks are generated by the repository's pinned official CMock 2.7.0. `mock_plat_memory` comes from the production `03_platform/rtos/memory/plat_memory.h`; `mock_platform_bsp_backend` comes from a synthetic function contract whose signatures mirror the vtable members in `04_impl/common/impl_{adc,can,dwt,flash,gpio,iic,pwm,spi,uart}.h`. They are generated artifacts, not hand-written substitutes.

Generate into a disposable directory and verify the committed copy:

```sh
./tests/scripts/cmock/generate.sh \
  --domain unit-platform-bsp --output /tmp/cod-cmock-platform-bsp
./tests/scripts/cmock/check.sh
```

Run all host tests or only this group:

```sh
./tests/run_tests.sh /tmp/COD_UniCFramework-build-platform-bsp
ctest --test-dir /tmp/COD_UniCFramework-build-platform-bsp -L platform_bsp --output-on-failure
```

CMock strict ordering is enabled. Every CMock-backed test initializes both generated mocks in `setUp` and verifies both before destroying either mock in `tearDown`.
