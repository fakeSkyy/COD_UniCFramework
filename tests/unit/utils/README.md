# 06_utils host tests

The existing `tests/unit/utils/suites/test_util_*.c` binaries provide dense Unity behavior coverage for all
15 compiled utility modules plus the header-only `util_assert`. The focused suites in this
directory add official CMock interaction coverage where utils crosses a dependency boundary:

- `util_log`: strict-order RTT prefix/body/CRLF call protocol and zero-call suppression paths;
  the behavior-suite RTT spy additionally records each variadic call to verify the actual level,
  tag, formatted body, and global order;
- `util_msgbus`: mutex initialization failure, pre-scheduler lock elision, scheduler-time lock
  success/failure, balanced unlock, task notification/wait forwarding, and seqlock paths that must
  not take the mutex.

Mocks are generated by the pinned official CMock 2.7.0 under `tests/cmock` and are committed so a
normal host build does not require Ruby.

Run all tests:

```sh
./tests/run_tests.sh /tmp/COD_UniCFramework-build-tests
```

Run only utils tests:

```sh
ctest --test-dir /tmp/COD_UniCFramework-build-tests -L utils --output-on-failure
```

Regenerate the mocks after changing a contract:

```sh
RUBY=/path/to/ruby ./tests/scripts/cmock/generate.sh \
  --domain unit-utils --output /tmp/cod-cmock-unit-utils
./tests/scripts/cmock/check.sh
```
